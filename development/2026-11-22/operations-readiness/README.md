## Netlify 운영 및 복구

- 운영 공개 HTML·sw.js·manifest는 main 파일과 바이트 단위로 일치했다. 공개 설정 함수의 연결 대상은 운영 프로젝트였다. 개발 사이트는 HTTP 401이었다.
- 저장소 설정에서는 앱 파일을 public/으로 복사하며 publish는 public, 함수 경로는 netlify/functions다. 실제 관리 콘솔의 Site ID, Base directory, Production branch, 환경변수 적용 범위, 자동 게시 트리거와 마지막 정상 deploy ID는 미확인이다. GitHub Actions 등록 워크플로 0개, GitHub main deployment API 기록 0개, 웹훅 열람은 HTTP 403이었다. 이전 PR에서 Deploy Preview가 자동 실행된 이력이 있어 이번에는 PR을 열지 않는다.
- 복구 순서: 게시 전 현재 운영 Deploy ID를 관리 콘솔에서 기록한다. 문제 시 그 배포를 다시 게시하고 운영 URL의 HTML·함수·PWA와 데이터 기준선을 확인한다. DB 복구는 앱 복구와 독립적으로 위 SQL 절차를 따른다.
