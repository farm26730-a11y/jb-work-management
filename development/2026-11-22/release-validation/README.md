## JB-DEV 전용 HTML 실행

[jb-dev-preview.html](jb-dev-preview.html)을 GitHub의 Raw 또는 다운로드 기능으로 내려받아 브라우저에서 연다. JB-DEV 프로젝트의 **Publishable Key**를 넣고 JB-DEV 테스트 계정으로 로그인한다. Supabase JS 라이브러리를 받아야 하므로 인터넷 연결이 필요하다. 미리보기 HTML에는 키나 테스트 계정 비밀번호가 포함되어 있지 않다.

- 대상 주소는 `https://apkrhhdmjxbvwtdktfaq.supabase.co`로 고정되어 있다. 저장된 운영 설정과 로그인 세션을 읽지 않으며 Netlify 공개 설정 함수도 호출하지 않는다. 브라우저 보안 정책 역시 해당 DB 주소에만 API 연결을 허용한다.
- 실제 Chromium에서 과거 운영 설정을 넣고 열었을 때 이를 무시하고, 비밀키 형식을 거부하고, JB-DEV에 고정된 클라이언트를 생성하는 것을 모의 인증으로 확인했다. 운영 주소에 대한 요청 시도는 브라우저의 정책에 의해 차단됐으며 네트워크 요청으로 전송되지 않았다.
- 현재 JB-DEV에 상시 설치된 보고 RPC는 운영 후보의 구현과 다르다. 이 파일의 사진 포함 보고를 실제 DB로 시험하려면 JB-DEV에 호환 RPC가 필요하다. 위 롤백 시험은 해당 DB 정의를 영구 변경하지 않았다. 로컬 HTML에서 Netlify 함수와 웹 푸시는 지원하지 않는다.

## 배포 전 남은 조치

- 운영과 분리된 환경에서 호환 RPC와 테스트 계정으로 실제 Storage 사진 업로드·재조회 및 푸시 수신을 확인한다. 운영의 타인 업무 댓글 사진 권한은 별도 정책 검토가 필요하다.
- 운영 SQL 적용과 승인된 앱 SHA의 main 병합·Netlify 게시에 대한 명시적 승인을 받는다. 변경 및 복구 절차는 [적용 계획](../report-comment-id-rollout.md)에 있다.
- 이 검증 기록과 미리보기는 운영 실행 HTML을 수정하지 않는다. 운영 main 병합, 운영 Supabase 수정, Netlify 배포 작업은 수행하지 않았다.
