## 개발 구현
### 서버 SQL (설치 전 검토본)
`development/2026-11-14/JB_V1_3_입사일기준_연차관리_설치전검토.sql`
- 직원 입사일 `jb_employees.hire_date` 추가(NULL 허용, 기존 값 유지)
- `jb_annual_leave_grants_v13`: 월/연 발생 확정 및 중복 방지
- `jb_annual_leave_adjustments_v13`: 도입 전 사용분/조정 사유 이력
- `jb_annual_leave_usage_v13`: 2일 이상 승인 연차의 소정근로일 기준 차감 일수
- RPC `jb_annual_leave_overview_v13`: 직원 본인, 관리자 본인+같은 부서 직원, 대표 전체 직원
- RPC `jb_annual_leave_set_hire_date_v13`: 입사일 관리자 등록
- RPC `jb_annual_leave_confirm_grant_v13`: 개근/80% 확인 후 1개월 단위 1일 또는 근속연수별 15~25일 확정
- RPC `jb_annual_leave_adjust_v13`: ± 조정 사유 저장
- RPC `jb_annual_leave_confirm_usage_v13`: 다일 연차 차감일수 확정
- 권한: 관리자는 자기 부서 **일반 직원**만 수정, 대표 전 직원 수정(대표 자신의 연차 관리 제외). 관리자 자신 발생·조정은 대표 권한.
- 직접 테이블 접근 제한: RLS ON / `anon`·`authenticated` 직접 권한 금지 / 인증된 직원만 RPC.
- 초기화 함수 보호: 신규 3개 테이블을 운영 초기화 대상에 포함하여 전체 24개 운영 테이블/8개 보존 테이블로 반영. **함수 정의만 변경; 데이터 초기화 절대 실행하지 않음.**
