## 6. 개발용 계정 최초 연결 (JB-DEV 전용, 운영 DB에서 절대 실행 금지)
- 새 개발 Netlify 사이트가 연결되면 테스트 이메일로 Supabase Auth 회원가입 → 이메일 인증.
- 가입 이후 **JB-DEV SQL Editor**에서 다음 템플릿의 이메일을 해당 *개발 테스트 계정 이메일*로 수정하고 **한 번만** 실행.
- 아래 SQL은 개발 대표 더미 레코드가 있는지 확인하고 그 레코드만 연결, 다른 직원/실제 데이터는 수정하지 않음.

```sql
DO $$
DECLARE
  v_auth_user_id uuid;
  v_count integer;
BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM public.jb_employees
     WHERE name='개발 테스트 대표' AND app_role='owner'
  ) THEN
    RAISE EXCEPTION '이 DB는 JB-DEV 테스트 프로필이 아닙니다. 실행 중단';
  END IF;
  SELECT id INTO v_auth_user_id FROM auth.users
   WHERE lower(email)=lower('test-owner@example.com')
     AND email_confirmed_at IS NOT NULL;
  IF v_auth_user_id IS NULL THEN
    RAISE EXCEPTION '인증 완료된 개발 테스트 계정 이메일을 확인하세요';
  END IF;
  UPDATE public.jb_employees
  SET auth_user_id=v_auth_user_id
  WHERE name='개발 테스트 대표'
    AND app_role='owner'
    AND auth_user_id IS NULL;
  GET DIAGNOSTICS v_count=ROW_COUNT;
  IF v_count<>1 THEN
    RAISE EXCEPTION '테스트 대표 연결 건수가 1건이 아닙니다';
  END IF;
END $$;
```

- 예시 주소 `test-owner@example.com`은 실제 이메일이 아님. 개발 테스트 가입자 이메일로 바꿔야 함.
- 개발용 대표 로그인 후 부서장·일반 직원 테스트 계정을 해당 역할의 **가상 직원 기록**에 연결하고 권한별 시험.
