## 운영 권한 / 화면 규칙
- 역할 `owner`(대표), `manager`(관리자·부서장), `staff`(직원).
- 직원 휴무 → 해당 관리자 홈 ‘확인 요청’에서 승인/반려 및 알림. 대표 홈은 일반 직원 휴무 대기를 표시하지 않는다.
- 대표는 본인 휴무 신청하지 않음. 관리자 자신의 휴무 신청은 자동 승인(사용자의 최신 변경 지시 기준).
- 직원의 ‘대표님 직접 보고’는 대표 홈 ‘확인 요청’에 표시, 대표만 처리.
- 업무 상태 예정/진행중/보류/완료. 댓글별 사진/업무 사진 분리, 예정·진행·보류 누적 시간, 완료 보관함 ‘상세 보기’ 유지.
- 식사 마감시간은 **저녁식사 신청 탭에만** `저녁식사 신청 마감시간 · 00:00분` 형식으로 표시; 다른 탭 상시 노출 금지.
- 부서 정렬 농원→밭팀→사무실→동이→쇼가든; 직급 대표→센터장→부장→과장→대리→주임→사원. 직원별 업무 화면의 휴무자를 임의로 맨 아래 보내지 않음.
- 실사용 갤럭시 우선. 직원 화면에 개발/모의 UI 노출 금지.

## 기능 및 실제 시험
- Resend SMTP 설정으로 기존 Supabase Auth 가입/재설정 이메일 발송. 확인 이메일 재발송·HTTP 429 제한 안내·링크 오류 안내 구현. 운영 가입→인증→로그인 성공 로그 확인. 이메일 확인 후에도 대표/관리자의 직원 계정 연결이 필요.
- 운영 Auth 계정 10건 중 인증 완료 9건(검사 당시); 푸시 구독 4개/직원 3명. 전체 직원 알림 수신 성공을 의미하지 않음.
- 보고/댓글/업무 등록 즉시 푸시 시도, 실패할 경우 1분 예약 발송. 댓글 한 건 중복 표시를 서비스워커 tag로 제한. **보고 등록과 댓글 등록이 동시 발생하면 서로 다른 2건의 알림이 같은 대상에게 올 수 있으니 실기기 시험 필요**.
- 서버에 댓글/업무 확인요청 테이블·RLS·관련 함수/트리거, 댓글 사진 `comment_id` 외래키 존재 확인.
- 배포 후 체크: Netlify Deploys 최신 SHA 및 Functions 설정 → 새 갤럭시 첫 접속 로그인 → 직원 가입·메일 인증 → 업무·댓글·보고·휴무 및 알림 도착시간 → 중복/화면꺼짐/다중기기 → 저녁 신청 마감 07:00 경계 → 사진·보관함. 검증하지 않은 항목은 완료라고 말하지 말 것.
